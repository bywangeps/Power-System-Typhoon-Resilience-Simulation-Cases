# Power-System-Typhoon-Resilience-Simulation-Cases
This repository contains the simulation and result data supporting the manuscript "Assessing Typhoon-Oriented Resilience of Power Systems: A Stochastic Multi-Stage Dual-Time Granularity Scheme with Dynamic Failures."

The following failure type codes are used throughout the result:
| Number | Failure |
|:----:|---------|
| 1 | Tower collapse |
| 2 | Windage (temporary) |
| 3 | Windage (permanent) |
